# 政点 · 考研政治

纯离线的考研政治刷题与背诵工具。刷题、模拟考试、知识点、思维导图、时间轴五合一，进度只存在本机，可安装为 PWA 或打包成安卓应用。

作者：Jayce919 · https://github.com/Jayce919

## 功能

- **刷题**：按学科与章节练习，单选、多选、判断三种题型；每题附解析，错项单独说明"为什么错"
- **模拟考试**：按真题结构组卷，倒计时、到期自动交卷，中途退出会提示确认
- **判断**：一句表述判对错，定位书本定义与易混点的背诵，共 1286 条
- **理论**：1054 个考点速查，按专题组织
- **导图与时间轴**：按主题串联考点，史纲部分按时间线排布
- **统计**：正确率、章节掌握度、错题分布
- **间隔重复**：按 SM-2 算法安排复习节奏
- **同步与备份**：设置页生成"进度码"，在手机与平板之间搬运进度；也可导出 JSON 备份

当前题库规模：1054 个考点、2245 道题，其中历年真题 594 道（2009–2026，每年 33 题齐全）。

## 技术栈

Vite + React 18 + TypeScript；`vite-plugin-pwa` 做离线缓存；Capacitor 6 打包安卓。无后端，全部状态存在浏览器 `localStorage`。

## 运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build      # PWA，输出 dist/
```

`dist/` 可直接部署到任意静态托管（Netlify / GitHub Pages），平板用 Chrome 打开后「添加到主屏幕」即可离线使用；也可以作为 Capacitor 的 `webDir` 打包 APK。

## 目录

```
src/pages       首页、刷题、模拟考试、理论、导图、时间轴、统计、设置
src/components  题目、图标、确认框
src/lib         内容索引、SM-2 调度、判分、状态存储、进度码、导航守卫
src/data        构建生成的学科、题库、时间轴、导图
知识点/         题库与知识点 JSON 源数据（parts/*.json、questions*.json）
tools/          内容构建与文档生成（build_content.mjs、render_md.mjs）
工具/           OCR 解析、质检、题库校对脚本与补丁
```

## 内容维护

仓库里已经带好构建后的数据（`src/data/*.json`），克隆下来 `npm install && npm run dev` 就能跑。

如果要改题库或知识点，走这条流水线：

```bash
npm run content    # 知识点/*.json → src/data/*.json（含结构校验）
npm run doc        # 生成 Markdown 版知识点文档
npm run build
```

数据源 `知识点/*.json` 是 OCR 脚本从扫描件生成的，不是手写。**改动一律走校对脚本，不要直接重跑解析脚本**——重跑会覆盖此前的清洗结果。脚本清单、执行顺序与断言规则见 [CLAUDE.md](CLAUDE.md)。

## 数据与隐私

无账号、无服务器、无埋点。答题记录、错题、复习进度全部写在本机浏览器，卸载或清除站点数据即清空。跨设备迁移靠进度码手动搬运。
